# Port-Scanner
## Script em Python que escaneia portas dentro de um intervalo enviado pelo usuário através de dois command line arguments (Porta início - Porta fim). Multithreading para diminuir o tempo de execução e uma verficação inicial do sistema operacional do usuário para conseguir executar o script perfeitamente.

- Status: em desenvolvimento.

- Pré-requisitos: Python, módulo psutil. Instale o módulo com:
- `sudo apt update`
  `sudo apt install gcc python3-dev`
  `pip install psutil`


- Execução: `python portscan.py [arg1] [arg2]`
